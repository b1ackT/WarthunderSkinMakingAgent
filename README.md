# Skin Studio 0.5 · 创作工作流

顶部改为「描述需求 → 添加素材 → 创作与调整」三步流程。分段设置和详细日志默认收起，素材区默认空白，演示入口已移除。

新增当前对话协作的创作 Agent 工作台。使用方法见 [AGENT-GUIDE.md](AGENT-GUIDE.md)，项目 Skill 位于 [skills/wt-skin-agent/SKILL.md](skills/wt-skin-agent/SKILL.md)。0.2 源码备份保留在 `backups/0.2/`。

本地皮肤工作台：平面图层编辑、模型实时预览、跨材质图片投射、Photoshop 保存后联动。仅编辑贴图，不修改模型几何。

这是独立的新版本。原来的 `../skin-editor` 和所有原始模型、贴图、皮肤文件均保留；本版本不加载现成的角色皮肤，也没有人物替换模板。

## 启动

双击 **启动 Skin Studio.cmd**，或在本目录运行 `npm start`，打开 http://127.0.0.1:8766 。需要 Node.js 18 或以上；启动脚本会检测 PATH 和常见安装目录，运行不依赖 npm 安装，也不需要联网、账号或上传文件。服务只监听本机回环地址。旧编辑器使用 8765，新版使用 8766，可同时运行。

建议把桌面浏览器最大化：左侧是材质、图层和属性，中间编辑 UV 贴图，右侧看模型。窄窗口中这些面板纵向排列。关闭运行窗口会停止文件联动和网页服务。

## 平面图层

- 添加图片、文字、色块、绘画图层，或把图片文件拖进平面画布。
- 图片支持位置、区域宽高、缩放、偏移、旋转、翻转。
- 图层可隐藏、复制、删除、排序，调不透明度，使用正常、正片叠底、滤色、叠加、柔光等混合模式。
- 图层列表上方是视觉上的上层。蒙版用擦除/恢复画笔编辑；绘画和橡皮针对绘画图层。
- 文字先输入内容、字体和颜色，再点“更新文字”。导出 PSD 时文字会栅格化。
- 滚轮缩放平面画布，空格拖动画布。支持撤销、重做和 Ctrl+Z / Ctrl+Shift+Z，保留最近 10 次编辑；撤销历史不写入工程。游戏导出规则不在撤销历史中。
- 双击模型表面选择对应材质；模型可旋转、缩放、平移、线框查看、截图及调预览亮度。亮度只影响预览，不改导出像素。

## 一张图横跨车体和炮塔

这四张图片是同一个 OBJ 空间中不同三角形组所使用的颜色贴图，**不是四个互不相关的模型**。共同的三维坐标使跨材质投射成为可能，四套 UV 则决定投射结果分别写到哪里。

1. 在模型上转到想贴图的角度，也可以使用左右侧视图。
2. 点击 **在模型上贴图**，选择图片；也能把图片文件直接拖到模型上的目标位置。
3. 当前投射视角会锁定。拖动虚线框定位，拖右下角缩放，或用大小和旋转滑块调整。
4. 勾选接受投射的材质，例如只选车体和炮塔。默认只贴当前可见表面，防止穿透到背面。
5. “实时试贴”会更新模型表面；“叠加显示平面参考图片”可另外显示参考平面。默认只看表面效果和定位框。
6. 点击 **确认投射到贴图**。每个实际覆盖的材质会得到自己的投射图层，它们引用同一个投射源。
7. 后续选任意一个关联图层，点 **编辑整组模型投射**，可以修改源图、整体位置、大小、角度，再重新投射。

单独删除某材质的投射层，会把该材质移出这一组；“删除整组模型投射”一次删除全组。复制投射层会生成独立的平面栅格图层。

可打开 `examples/HSTV-L-跨材质投射.studio.zip` 试用：一张校准图跨越车体和炮塔，源图片、投射参数和独立 UV 图层都保留着。

### 投射的实际边界

- 同一 UV 像素如果被多个模型表面共用，图案会在这些表面重复。这是源模型 UV 的限制；只改皮肤无法给共用 UV 的两面写不同像素。
- 投射按选定视角记录，斜面会产生透视拉伸。被遮挡区域不会涂上，需要换视角再补一层。
- 车体和炮塔可在静止姿态下对齐；游戏里炮塔旋转后，两部分图案自然会分开。
- 为保留细节，投射不画到几乎与视线平行的背缘；不是环绕曲面的自动展开或无缝修复器。

## Photoshop 联动

联动是 **PS 保存文件 → 本地读取新合成图 → 刷新模型**。不需要 PS 插件，也不读取未保存的画布。不会自动启动 PS，不会改动源 PSD。

### 继续用 PS 制作整张贴图

1. 选中材质，点 **导出当前材质为分层 PSD**。
2. 在 PS 打开导出的文件。包含底图、当前栅格图层和隐藏的 UV 参考层；显示 UV 层作定位参考，保存最终贴图前关闭它。
3. PSD 使用 RGB / 8 位，并开启最大兼容性，以便保存可供读取的合成图。
4. 在 Skin Studio 左侧“Photoshop 文件联动”中，选择 **当前材质的 PS 合成图层**，选择或填写 PSD 完整路径，点 **开始联动**。
5. 在 PS 修改并保存，通常约 1–3 秒后模型更新，较大的 PSD 会更久。

PS 合成图会成为材质最上方的一个图层，避免对已经合并的效果再次叠加。断开联动后，最后同步的图片图层仍保留，可隐藏或删除以显示下方原有编辑层。导出 PSD 是一次性分层导出；之后 PS 图层结构不会反向变成 Studio 的可编辑图层树。

### 修改跨材质图案的源图片

先选中一个投射图层，把“同步到”改为 **当前整组模型投射**，再连接 PSD 或 PNG。每次保存都会用原投射位置重新计算这一组，自动更新车体、炮塔等所有目标材质。只需要编辑同一张源图片。

另外支持 **当前图片图层** 和 **当前材质底图** 两种联动。底图模式会继续叠加本地图层，适合更新干净底图；与读取已经合并好的完整皮肤不是同一种用途。

### 联动格式和限制

- 支持 RGB / 8 位兼容 PSD，PNG、JPG、WebP、TGA、未压缩 32 位 DDS。
- 暂不支持 PSB、CMYK、16/32 位 PSD，以及 DXT / BC 压缩 DDS。遇到这些格式请另存 RGB / 8 位兼容 PSD 或 PNG。
- 完整材质/底图的像素尺寸必须与当前材质相同，图层图片和投射源的尺寸不受这一对应限制。
- 如果 PS 保存时短暂替换文件，工具会等待并重试。文件不存在、格式错误或尺寸不符会显示在联动列表，保留上次成功预览。
- 外部同步不加入逐次撤销历史。需要保留版本时请保存工程或在 PS 中保存源文件副本。
- 工程保存图像快照，不保存自动连接外部文件的权限；重新打开工程时需手动重新连接源文件。

PSD 合成图兼容性的依据：[Adobe 文件格式说明](https://helpx.adobe.com/ph_en/photoshop/desktop/save-and-export/export-files-to-different-formats/image-file-formats-supported-in-photoshop.html)。PSD 读写使用 [ag-psd](https://github.com/Agamnentzar/ag-psd)，本工具采用栅格图层和已保存的合成图，不重算 PS 的智能对象、滤镜或矢量效果。

## 工程、模型与游戏导出

**保存工程**输出 `.studio.zip`，包含底图、图层、蒙版、投射源图片、投射参数、当前视角与模型。其他模型支持一个 OBJ、配套 MTL 和颜色贴图的 ZIP 包。MTL 需使用普通 `map_Kd` 文件路径，暂不解析带变换参数的贴图路径。文件名请保持唯一。

**导出皮肤**输出未压缩 32 位 DDS 和 BLK。HSTV-L 使用 `us_hstv_l.blk`；其他模型需核对各材质 `from` 纹理名及游戏模板的 BLK 文件名。解压到 `War Thunder/UserSkins/自定义目录/`，在游戏个性化中刷新用户涂装。

固定载具颜色贴图默认使用 `set_tex` + `param:t="camo_skin_tex"`。旧内置工程中不正确的 `replace_tex` + camo 参数组合会在导出时迁移为固定涂装规则。若明确选择直接替换 `_c` 贴图，则导出黑色 Alpha 并移除 camo 参数，否则原车迷彩会覆盖新颜色。依据 [官方用户涂装文档](https://wiki.warthunder.com/cdk/creation_camo)。修改编辑器版本后，请先保存当前工程，再刷新并重新打开工程，让后续导出使用更新后的代码。

本版默认 HSTV-L 底图来自提供的原车 JPEG：车体 2048×2048、炮塔 2048×1024、主炮 1024×512、机枪 256×256。JPEG 没有原始 DDS 的 Alpha，默认导出 Alpha 为 255；导入同尺寸原始 DDS 后会保留其 Alpha。此版本只导出颜色贴图，保留游戏原本的法线/材质贴图，不使用旧皮肤的 `n.dds`。输出不生成 mipmap。

这是贴图制作工作台，不是完整 Photoshop。浏览器材质和照明是近似预览，尚未在战争雷霆客户端内实测。游戏文件规则可参考[官方用户皮肤文档](https://wiki.warthunder.com/cdk/creation_camo)。

## 结构与验证

- `app.js`：图层编辑、工程、材质和 PS 联动界面。
- `projection.js`：世界坐标到 UV 的投射、深度遮挡和窗口比例适配。
- `image-io.js`：PSD/TGA/DDS/普通图片读取和 DDS 写出。
- `server.cjs`：本机静态服务、文件选择和只读文件联动 API。
- `model-analysis.json`：提供模型的材质/UV 分析。
- `verification.json`、`tests/`：验证结果和可重复检查。

运行 `npm test` 检查 UV 分组、平铺 UV 边界、窗口比例、文件联动、原子保存与 API 访问控制。打开 `tests/gpu.html` 并点 Run，可在真实浏览器 WebGL 中检查跨材质、遮挡、像素颜色、镜像、PSD 和 DDS。验证阶段使用受控 PSD 文件模拟保存，并检查了实际 HSTV-L 结果；没有通过 Photoshop 应用本身进行 UI 自动化，也没有修改用户的 PS 文档。


## 远近渐变皮肤（0.5）

先保存当前工程，再刷新编辑器加载新版。侧栏展开“可变皮肤 · 远近渐变”，启用后把图层分配到共用、近景、中景、远景；可将选中图层整组复制到另一个距离。投射组跨材质保持关联，复制出的距离版本独立编辑。旧工程默认共用、关闭距离模式。

用近/中/远按钮与层级滑块对比构图，或选自动模式后缩放、旋转模型，查看真实 mip 采样。近景为层级0，中景和远景层级可改，支持平滑/线性过渡。手动预览以工作分辨率对比图案，自动模式才模拟纹理缩小。小贴图的 mip 数有限，请把远景锚点设在其 mip 范围内。关闭距离模式时采用共用+近景，工程保留中远景图层。

启用后导出完整 DDS mip 链（直至1×1）和 `distance-layers.json`，不受当前预览滑块影响。仍沿用已经修复的 BLK 和 Alpha 导出规则。具体切换距离受画质、角度、屏幕分辨率和游戏纹理处理影响，需在游戏内验证，不能用层级换算固定米数。

Agent 的任务设置增加“制作近/中/远渐变皮肤”和参考检索重点。允许检索时，Skill 会先检索并查看匹配的痛车实车参考，记录来源和构图结论，再结合侧装甲预览优化脸部、斜向构图与文字留白。图片、人物、背景、装饰和文字仍为独立源文件和图层，没有新增预设素材或自动模型API调用。修改任务设置的服务端字段后，下一次启动服务生效；当前画布先保存再重启/刷新。

浏览器距离功能验证：`node tests/browser-check.cjs`（需本地服务启动与 Chrome），在独立 profile 与禁用 Agent 同步的测试画布运行，不覆盖当前任务。

创作流程顶部现有常驻 Mipmap 可选开关及近/中/远预览入口，和侧栏双向同步；默认关闭。任务提交与画布使用同一份设置，恢复工程和 Agent 改动后自动同步。

启动诊断：在命令提示符中运行 `"启动 Skin Studio.cmd" --check`，可检查 Node 版本和必需文件。从 GitHub 下载时请先完整解压目录。重复双击会打开已有 Studio；其他程序占用端口时会显示错误，不会结束该程序。
