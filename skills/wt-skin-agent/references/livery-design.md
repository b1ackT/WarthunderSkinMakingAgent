# Pain-car / itasha design research

Use for initial compositions and user feedback about placement, tilt, readability or racing style. Research should lead to changes, not a collection of unrelated images.

1. Read the brief, `researchFocus`, user artwork, current model and latest feedback. Search the named style/series with terms such as `itasha side livery`, `痛車 サイド デザイン`, `レーシング 車両 デザイン`. Prefer official team galleries, designers and event/vehicle owners; GSR is a reference only when relevant to the brief.
2. Inspect useful actual side views, not only search snippets. Log 2–4 relevant source links when available. Identify where the face, torso, typography, large color blocks and panel seams sit. Distinguish what is observed from your own proposed adaptation.
3. Plan for the actual surface. Cars and tanks have different proportions. Keep faces readable on continuous armor; avoid slicing eyes/mouth across turret joints, rails, protrusions or wheel UVs. A diagonal should use the wide panel's length. Account for the source character's existing lean before choosing an additional rotation.
4. Describe tilt in the visible side view: “head upper-left, dress lower-right”, for example. Do not infer perceived clockwise direction from an untested numeric rotation. Preserve artwork aspect ratio. Preview the model from the intended side; correct position, angle and crop before claiming success.
5. Use the character as the visual focus, match nearby graphic lines to its motion and leave clear space around lettering. Translate the reference's hierarchy instead of copying sponsor logos or flattening everything into one bitmap. User-requested targeted edits stay targeted unless they authorize a broader redesign.
6. Log concise observations, intended adaptation and actual results with source links. Keep downloaded references separate from the user's editable art; do not populate a preset library. If a reference cannot be inspected, say so and use another accessible source or the user's images.

Useful starting source when an AMG racing-itasha style is requested: https://www.goodsmileracing.com/team2025/ . Search for the matching year and official side-view images instead of assuming every year's design is the same.
